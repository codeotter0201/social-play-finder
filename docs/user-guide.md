# 網站使用指南

適合拿到場次網站、想找場次及比較資訊的人。直接用瀏覽器開啟提供的 `index.html`；不需要安裝爬蟲、Codex 或開發工具。網站顯示的是發布時的資料快照，不會自動取得 Facebook 最新貼文。

## 選擇地區

網站入口提供「雙北」與「台中」，選擇後只載入該區資料；場次頁上方可切換地區或回到入口。尚未發布的地區會顯示說明。地區代表來源資料集，場次實際位置仍以場馆與原文為準。各區分開更新；切換頁面後不保留目前的篩選與選取。

## 先找到想打的場次

1. 在「搜尋」輸入地區、場館、程度或原文關鍵字。
2. 視需要設定玩法、新手友善、費用上限、最早開始時間、日期或星期。
3. 下方會立即更新結果筆數，已套用條件顯示為細框標籤。點標籤的 × 取消該條件，或按「清除條件」全部重設。

| 條件 | 如何理解 |
| --- | --- |
| 搜尋 | 比對包含原文、場館、地區等資訊的文字；輸入完整片語時依該片語搜尋 |
| 玩法 | 單選。雙打（全部）包含男雙、女雙、混雙；單打（全部）包含男單、女單。選特定玩法時只顯示明確標示該值的資料 |
| 新手友善 | 適合新手／非新手只匹配已判讀的資料；未知資料在「不限」時保留 |
| 費用上限 | 比較最低已列方案的總金額，不是每小時費用；價格未知的場次不會匹配金額上限 |
| 最早開始時間 | 例如 12:00，顯示 12:00（含）之後開始的場次，不包含較早開始但尚未結束的場次 |
| 日期、星期 | 日期查明確日期；星期同時檢查明確日期與固定週期 |
| 日期與星期符合方式 | 兩者皆填時，可選符合其中一項，或同時符合兩項 |
| 包含重複 | 顯示原本隱藏的確定重複場次；可能重複的資料原本就會保留 |

除日期與星期的組合外，不同條件需要同時符合。選了玩法卻沒有結果，可能是資料尚未標示玩法，取消此條件可看完整集合。網站包含已滿或取消的貼文資訊，請在詳情及原文確認是否仍能報名。

## 閱讀與排序

「程度／用球／單場人數」欄位依序顯示程度、用球，以及「場地：…面；總人數：…人」。場地面數與總人數直接沿用已抽取值，不換算每面人數，也不顯示缺額；缺值各自標示「未標示」。比較預覽與複製內容同步顯示，點選欄名仍依程度排序。

網站預設「不分組」，每列有自己的日期與時間。切換「日期分組」後，日期放在群組標題，同日期的場次放在一起。

桌面與手機都直接點欄位標題排序：**第一次升序、第二次降序、第三次取消**。聯絡與原文不提供排序。

- 不分組：跨所有日期依所選欄位排序；取消後回到預設日期、時間順序。
- 日期分組：通常只排序組內場次；日期表頭可調整日期群組順序。取消後恢復預設日期群組及組內時間順序。
- 日期排序：固定週期在前、明確日期其次、日期未知最後；升降序改變各類別內的順序。
- 未知值排在最後；兩種模式各自保留排序狀態。清除條件會回到不分組及預設排序。

手機將每筆資料呈現為卡片，左側是欄位名稱、右側是數值；排序按鈕在卡片上方，空間不足時換行。右下角 ↑／↓ 可快速移到整頁頂部／底部，到達該端時對應按鈕隱藏。

## 費用與玩法代表什麼

| 欄位 | 說明 |
| --- | --- |
| 時數 | 依起訖時間計算，`2.5 HR` 是 2 小時 30 分鐘；「次日」表示跨午夜 |
| 費用（元） | 最低已列方案金額，可能附帶性別、同行或其他條件 |
| 每小時費用 | 例如 `100/hr`；優先用最低價方案自己的時數，未提供才以場次時數換算。同一最低價有多個時數時採最低換算值，無法計算留空 |
| 玩法 | 雙打、男雙、女雙、混雙、單打、男單、女單。混雙指男女搭配，雙打則未限定搭配；空白不是預設雙打 |

「每週日」等固定週期不保證某一週一定開團。查看「詳情與原文」的完整價格條件、聯絡方式及警告，必要時向主揪確認。

## 查看來源與過濾作者

- **原貼文 ↗、作者頁 ↗**：綠色可開啟連結，灰色代表缺少網址、不可點。展開原文後，若有來源網址，也可直接點原文前往貼文。
- **詳情與原文**：展開或收合原文、費用條件、報名方式與資料提醒。
- **作者名稱**：有可辨識作者時，點名稱開啟選單；可用時提供「前往 Facebook 個人檔案」，並保留「過濾此作者」，點選過濾後才排除。再次點名稱、點外部、按 Esc 或捲動可關閉選單。個人檔案選項依作者來源連結建立；原本的「作者頁 ↗」連結保持原樣。

被排除的作者會出現在上方條件標籤，可個別取消或透過「清除條件」解除。匿名或缺少可靠作者識別的資料不提供作者過濾；它不會只因名字相同就排除其他作者。

## 選取、比較與複製

1. 點場次列或手機卡片的內容區即可選取，會出現淡綠底；再次點擊取消。連結、作者及詳情入口不會誤觸選取。鍵盤可聚焦場次後按 Enter／空白鍵切換。
2. 往下查看「已選場次」。每張預覽卡包含結構化資訊、來源連結與預設展開的完整原文；按「移除」取消單筆。
3. 按底部工具列的「複製內容」，取得 Markdown 比較表及原文附錄，可貼到訊息、筆記或 AI 工具。比較預覽與複製內容包含用球、留言／私訊等報名方式及已取得的報名連結；來源附錄保留原貼文、作者原網址、作者個人檔案、來源社團與擷取時間。同篇貼文的原文只附一次。缺少的資料標示未提供／未標示，不以作者網址代替貼文網址。

最多選取 **50 場**；完整複製內容上限 **100,000 個 Unicode 字元**，包含原文、網址、換行及表格格式。超過時不能複製，需要移除部分場次，原文不會被截斷。瀏覽器不允許直接複製時，頁面會提供文字框，按 ⌘C 或 Ctrl+C 手動複製。

篩選、排序或過濾作者不會清掉已選場次；已選但被排除的作者會在預覽中提醒。「清空選取」才會一次取消全部。重新整理或關閉頁面不保留選取與作者過濾狀態。

## 下載與資料更新

「下載 CSV」取得該頁完整主場次集合，不是目前篩選或選取的子集合。只想分享選取的資料請用「複製內容」。「匯出查詢設定」給需要在 CLI 重用條件的操作人員，一般瀏覽不必使用。

若顯示「來源已有新版，整理尚未更新」，代表目前仍保留前次整理結果。分類或玩法空白，也可能是舊抽取尚未補齊。拿到更新版頁面後重新開啟即可；如果需要爬取或重新抽取資料，交由操作人員依[操作指南](development/post-etl-operations.md)處理。
