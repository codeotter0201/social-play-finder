# 以本機 SQLite 追加保存貼文觀察

Chrome 擴充功能維持無後端與無 Native Messaging，只負責產生標準 JSON；本機 Node CLI 將 JSON 原文與每篇貼文觀察追加至標準 SQLite 檔。貼文網址是主要識別鍵，缺少網址時依序使用社團範圍內的貼文 ID 與內容指紋；相同邏輯 JSON 重複匯入不追加觀察，既有歷史及觀察 ID 保留。

一般查閱與抽取以每個識別鍵最新合法擷取時間為準，同時刻再依寫入時間及觀察 ID 選取，避免晚匯入舊檔倒退內容；無合法擷取時間的觀察僅在全部皆無合法時間時才以寫入時間後援，並顯示品質警告。抽取任務、嘗試紀錄與發布狀態擴充在同一本機庫；產物以完整批次目錄與原子切換的讀取位置保持一致。
