# 搜尋回答格式

先寫一行篩選解讀，再顯示全部符合的場次組。每組至少包括：

- 日期／週期與時間。
- 場館、行政區或地址。
- 完整程度文字。
- 完整費用文字。
- 報名 instructions。
- 至少一個真實聯絡入口。
- 符合使用者目的的原因。

推薦格式：

```text
9/2（三）15:00–18:00｜秘密基地羽球館（板橋）
程度：不限程度，新手／初學者可參加
費用：原文未公開，請聯絡確認
報名：點作者頭貼私訊
聯絡：[開啟原貼文]｜[開啟作者 Mi Nnie 的頁面]
適合原因：週三 18:00 前開打，程度不限
```

聯絡入口：

- 報名 URL：`[直接報名](...)`
- LINE ID：顯示原值；只有 raw data 已有 LINE URL 時才能附連結。
- 電話：顯示原值。
- post URL：`[開啟原貼文留言／查看最新狀態](...)`
- author URL：`[開啟作者 Name 的頁面私訊](...)`

禁止輸出：

```text
不限程度｜未標示｜FB私訊
```

沒有可用入口的資料不能進主要推薦。若無結果，區分「沒有符合硬條件」「費用或程度待確認」「符合但沒有聯絡入口」。最後附完整 filtered CSV 路徑。
